Cryptographic Architecture (Why & How)

Standard NIST & IETF Algorithms
🔒 1. Fernet Symmetric Encryption (AES-128-CBC + HMAC-SHA256)

Purpose: Protect citizen privacy by encrypting precise GPS coordinates and vehicle hardware identifiers stored in the database.

Keys are kept in local files (data/keys/secret.key), never exposed to client-side browsers or web logs. Decrypted only when requested by authorized municipal administrators.

🛡️ 2. SHA-256 Canonical Hashing (Data Integrity)

Purpose: Guarantees that neither a malicious actor nor database corruption has altered detection values after acceptance.

A canonical JSON string of core fields (sorted keys, uniform float rounding) is hashed into a 256-bit hexadecimal digest. Modifying even 1 bit produces an avalanche effect that permanently invalidates the hash.

✍️ 3. RSA-2048 Digital Signatures (Authenticity & Non-Repudiation)

Purpose: Proves that the official municipal server accepted and signed the record.

Signed with server's 2048-bit private key (private_key.pem) using PKCS#1 v1.5 padding and verified by anyone holding the public key (public_key.pem).

Project Architecture & Teacher Viva Quick-Reference

Academic Coursework Defense

1. How does the Machine Learning Pipeline work?

Raw multi-axis accelerometer (\(a_x, a_y, a_z\)) and gyroscope (\(\omega\)) signals are processed to extract 6 kinematic features: accel_mag_mean, accel_mag_max, accel_mag_std, accel_z_delta, accel_jerk, and gyro_mag_mean. A Random Forest Classifier (100 estimators) trained with stratified cross-validation classifies the event into Normal Road, Speed Breaker, or Pothole.

2. How does DBSCAN Geospatial Clustering work?

We use scikit-learn's DBSCAN with the Haversine metric, converting coordinates to radians. Distance threshold \(\epsilon = 50\text{ meters}\) and \(min\_samples = 2\). This clusters multiple reports from different vehicles driving over the exact same physical pothole into a single consolidated municipal work order.

3. What is the Pavement Distress Index (PDI) formula?

\(PDI = \min(100, (\text{Base} + K_{\text{shock}}) \times C_{\text{factor}} + B_{\text{freq}} + B_{\text{consensus}})\). Base weights: Normal = 5, Speed Breaker = 35, Pothole = 70. \(K_{\text{shock}}\) scales with peak impact G-force; \(B_{\text{consensus}}\) grants bonus urgency when independent distinct vehicles verify the anomaly.

4. What is the role of Cryptography in this civic project?

Privacy: Precise home/work commute GPS coordinates are encrypted using Fernet symmetric encryption.
Integrity: SHA-256 hashes detect any unauthorized database alteration.
Authenticity: RSA-2048 digital signatures prove the municipal server verified and authenticated the telemetry report.
